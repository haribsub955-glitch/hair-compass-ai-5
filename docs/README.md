# Hair Compass AI Public Pages

This folder is ready to publish with GitHub Pages.

## Files

- `index.html`
- `privacy-policy.html`
- `support.html`

## Before Publishing

Replace these placeholders:

- `[DATE]`
- `[SUPPORT EMAIL]`
- `[SUPPORT URL]`

## GitHub Pages Setup

1. Push this repository to GitHub.
2. Open `Settings` for the repository.
3. Open `Pages`.
4. Set the source to `Deploy from a branch`.
5. Choose your main branch and the `/docs` folder.
6. Save.

Your URLs will look like:

- `https://YOUR-USERNAME.github.io/YOUR-REPO/`
- `https://YOUR-USERNAME.github.io/YOUR-REPO/privacy-policy.html`
- `https://YOUR-USERNAME.github.io/YOUR-REPO/support.html`

## App Update

After publishing, update the placeholders in:

- `Hair Compass AI 5/ContentView.swift`

Set:

- `AppSubmissionLinks.privacyPolicyURL`
- `AppSubmissionLinks.supportURL`
